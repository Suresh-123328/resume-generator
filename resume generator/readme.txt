# AI Resume Generator

This project uses Streamlit + Google Gemini 1.5 Pro to build AI-based dynamic resumes.

## Features
- Generate complete resumes instantly
- Accepts name + job role
- AI generates summary, skills, experience, projects
- Clean UI using Streamlit
- Export or copy resume easily

## How to Use
1. Install Python
2. Install Streamlit + Google Generative AI
3. Add your Gemini API Key
4. Run the web app
5. Enter name + job role
6. Click "Generate Resume"
